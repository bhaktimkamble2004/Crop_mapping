Baramati SAR Agricultural Land Classification 2026#
A GitHub Pages website for the Advanced Remote Sensing project: Multi-Temporal Sentinel-1 SAR-Based Agricultural Land Classification of Baramati, Maharashtra, 2026.

Files#
index.html – webpage content
style.css – responsive styling
script.js – interactive Leaflet map and charts
assets/Layout.jpg – final cartographic map layout
assets/Baramati_SAR_Classification_FINAL_2026.tif – optional final GeoTIFF (add this file yourself)
Interactive map#
The website links directly to the published Google Earth Engine application:

https://bhakti-ee.projects.earthengine.app/view/cropmapping

This is the project's interactive classification map. The local Leaflet map remains as study-location context.

GitHub Pages#
Create a new public GitHub repository.
Upload all files and folders from this project.
Open Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select branch main and folder /(root).
Save.
Wait for GitHub Pages to provide the public URL.
Important academic note#
The area statistics displayed on the page are the known values from the original classification before the later spatial filtering step:

Active Cropland: 10,355.87 ha
Fallow Agricultural Field: 1,537.44 ha
Non-Cropland: 3,613.23 ha
Overall Accuracy: 79.89% Kappa: 0.647

A verified class-mean VV/VH temporal-signature dataset was not available when this site was generated, so the website does not fabricate a temporal plot. Replace the temporal note with a real exported temporal chart if one becomes available.
